# Архитектура платформы: commerce для автозапчастей

Единый цифровой канал продаж и лидогенерации: розница, опт, менеджеры, SEO.

---

## 1. Три контура платформы

| Контур | Описание |
|--------|----------|
| **B2C** | Розничные продажи |
| **B2B** | Оптовые продажи, персональные цены, заявки, счета |
| **Content + SEO** | Органический трафик по брендам, моделям, OEM, VIN, категориям |

Не «просто сайт», а **каталожно-коммерческая система**.

---

## 2. Шесть слоёв системы

### 3.1. Презентационный слой
Сайт, каталог, карточки товаров, корзина, checkout, кабинет клиента, кабинет оптовика, блог/справочник/FAQ.

### 3.2. Каталожный слой
Бренды, модели авто, поколения, двигатели, категории запчастей, OEM-коды, аналоги, совместимость (fitment), наличие, цены, сроки поставки.

### 3.3. Коммерческий слой
Розничные/оптовые цены, price tiers, акции, скидки, корзина, заказы, invoicing, запрос КП.

### 3.4. CRM / Sales Ops
Лиды, запросы по VIN, оптовые регистрации, заявки на прайс, статусы заказов, повторные продажи.

### 3.5. Контентный слой
SEO-страницы, статьи, гайды, страницы брендов/категорий, FAQ, условия доставки/возврата/гарантии.

### 3.6. Интеграционный слой
ERP/склад, поставщики, платежи, курьеры, email/SMS/WhatsApp, аналитика, CRM.

---

## 4. Информационная архитектура (sitemap)

### Публичная часть

- **Главная** — hero с поиском (артикул/OEM/VIN), выбор по авто, категории, бренды, акции, блок для опта, преимущества, доставка/возврат, отзывы, FAQ, CTA.
- **Каталог** — вход по категории, бренду, марке/модели, OEM, VIN, поисковая строка.
- **Категории** — Двигатель, Фильтры, Тормозная система, Подвеска и рулевое, Сцепление и трансмиссия, Электрика, Охлаждение и кондиционирование, Кузовные детали, Освещение, Масла и автохимия, Аксессуары и др.
- **Страницы брендов** — Bosch, Mann-Filter, SKF, Sachs, Valeo, Brembo, Febi, Mahle и др.; описание, категории, подборки, SEO.
- **Подбор по автомобилю** — Марка → Модель → Год/поколение → Двигатель → Тип кузова → Категория запчастей → Совместимые товары.
- **Поиск по OEM / артикулу** — OEM, supplier SKU, internal SKU, EAN, cross references.
- **VIN-запрос** — форма VIN, фото техпаспорта, телефон/email, тип клиента, комментарий, SLA ответа.
- **Карточка товара** — название, бренд, SKU, OEM, цена, опт/«войдите как партнер», наличие, срок, фото, совместимость, характеристики, аналоги, CTA (корзина, VIN, опт).
- **Корзина** — товары, количество, сроки, промокод, тип клиента, доставка, оплата, cross-sell.
- **Checkout** — гость/регистрация, B2B checkout, invoice/VAT, доставка, оплата, итог.
- **Страницы доверия** — О компании, Доставка, Возврат и гарантия, Оплата, Контакты, Privacy, Cookies, Termeni și condiții, ANPC при необходимости.
- **B2B / Оптовикам** — кому подходит, преимущества, персональный менеджер, индивидуальные цены, прайсы, отложенная оплата, заявки, форма регистрации.
- **Блог / Справочник** — подбор запчастей, OEM vs aftermarket, гайды по маркам/VIN, сравнения брендов, кейсы для сервисов.

### Роли

- **Гость** — поиск, каталог, покупка в розницу, VIN-запрос, регистрация.
- **Розничный клиент** — покупки, история заказов, адреса, уведомления.
- **Оптовый клиент** — свои цены, заказы партиями, документы, быстрый заказ по SKU, запрос КП, связь с менеджером.
- **Менеджер продаж** — заявки, VIN, цены, перевод в B2B, предложения.
- **Контент-менеджер** — страницы, SEO, статьи, баннеры, категории.
- **Админ / Operations** — каталог, цены, наличие, пользователи, интеграции, отчёты.

## 7. Каталожная модель данных

**Сущности:** Product, Brand, Category, Vehicle Make, Vehicle Model, Generation, Engine, Fitment, OEM Code, Cross Reference, Warehouse Stock, Supplier, Price Tier, Delivery ETA, Media, Documents.

**Ключевые поля товара:** internal SKU, manufacturer SKU, OEM number(s), brand, category, short name, full title, compatibility, stock, lead time, retail/wholesale price, VAT, weight/dimensions, images, specs.

**Связи:** товар ↔ аналоги, товар ↔ совместимые авто, товар ↔ OEM, товар ↔ похожие/cross-sell.

## 8. Навигация (верхний уровень)

Каталог | Подбор по авто | Поиск по OEM/артикулу | Оптовикам | Акции | Бренды | Блог/Полезное | Доставка и оплата | Контакты.

**В шапке:** поиск, телефон, WhatsApp, вход/кабинет, корзина, язык, CTA «Запрос по VIN».

- **Russian** — по необходимости.
- **English** — нейтральный B2B слой.

## 10–11. Страницы и функциональность

- **Главная** — ассортимент, удобство подбора, B2B-надежность.
- **Категория** — title/description, фильтры, сортировка, SEO-текст, FAQ, листинг.
- **Листинг** — фильтры: бренд, цена, наличие, срок, тип, совместимость, OEM, характеристики.
- **Карточка товара** — conversion point №1.
- **B2B лендинг** — conversion point №2.
- **VIN form** — conversion point №3.

**MVP:** каталог, поиск, фильтры, карточки, корзина, checkout, кабинет, VIN-запрос, B2B регистрация, CMS, блог, аналитика, email.

**Этап 2:** персональные B2B цены, заказ по Excel/SKU, мультисклад, live stock, supplier feeds, рекомендации, abandoned cart, loyalty, wishlist, compare.

**Этап 3:** API, DMS/ERP, кабинет сервиса, auto-repricing, AI-поиск, интеллектуальные аналоги.

---

## 12. Коммерция

- **Цены:** розница, акция, B2B tier, volume-based, manual negotiated.
- **B2B:** подтверждение компании, price tier, отсрочка, лимиты (позже), персональный менеджер.
- **Документы:** invoice, proforma, доставка, возврат/гарантия.

---

## 13–14. SEO и контент

**SEO-кластеры:** купить [категория] для [марка] [модель], [OEM], [brand] [part], запчасти для [марка], [product] [engine], подбор по VIN, оптовые автозапчасти Румыния/București.

**Типы страниц:** категория, бренд, марка/модель авто, бренд+категория, авто+категория, OEM landing, статьи/FAQ.

**Контент:** guides, FAQs, сравнения, страницы брендов, buying guides, service pages, B2B pages.

---

## 15. Доверие

Чёткие контакты, юр. данные, прозрачные условия, сроки поставки, возврат, способы связи, social proof, B2B onboarding.

## 18–19. Интеграции и поиск

**Интеграции:** платежи, курьеры, email/SMS, ERP/склад, supplier imports, CRM, аналитика, cookie consent.

**Поиск:** текст, OEM/SKU exact, fuzzy, подсказки, бренды, категории, модель авто, аналоги, синонимы/опечатки; понимание: код / бренд / описание / автомобиль / симптом.

---

## 20. Дизайн

Коммерчески надёжный: чистый, индустриальный, технологичный, сильная каталогизация, без перегруза. Тон: профессиональный, быстрый, надёжный, B2B-friendly.

## 21. Фазы запуска

- **Фаза 1 — Launch:** главная, каталог, категории, карточки, поиск, подбор по авто, VIN, B2B страница, корзина, checkout, legal, контакты, кабинет.
- **Фаза 2 — Growth:** персональные цены, SEO, блог, рекомендации, abandoned cart, оптовый кабинет, быстрый заказ.
- **Фаза 3 — Scale:** supplier sync, API, ERP, repricing, multiwarehouse, marketplace.
